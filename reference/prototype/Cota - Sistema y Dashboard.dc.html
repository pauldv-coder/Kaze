Sistema de diseño y dashboard del proyecto

Dos direcciones que comparten una misma base de tokens, para que elijas el registro antes de construir el resto de pantallas. El dato manda la jerarquía; el color comunica estado, nunca decora.

Dirección A · Instrumento

Densa, técnica, grid a la vista. Para la vista del consultor: A3, Kanban y KPIs con máxima información por pantalla.

Dirección B · Informe

Aireada, editorial, presentable. Cercana a la vista de cliente: pocos números, grandes y claros, lista para proyectar o exportar.
