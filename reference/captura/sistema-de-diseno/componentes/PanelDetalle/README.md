# PanelDetalle

Panel lateral de 380px con la ficha completa de una actividad seleccionada.

Adición del módulo. Se abre al seleccionar una fila de `TablaActividades` o una tarjeta del tablero, sin perder la tabla de vista. Flota con `shadow-lg`.

El consumidor pasa `secciones` (Básico · Entregable · Tiempos · Recursos · Reglas y problemas · Fuente) con sus `campos`; un campo sin `contenido` se pinta con `ValorCampo`, así lo desconocido nunca parece vacío. `pie` recibe las acciones («Confirmar», «Aceptar sugerencia»).
