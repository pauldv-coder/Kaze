# EtiquetaVersion

Distingue el proceso actual (As-Is) del propuesto (To-Be), con número de versión opcional.

Adición del módulo. As-Is es un chip lleno `color-tinta`; To-Be es blanco con borde discontinuo `color-tinta`: la línea discontinua dice «aún no es la realidad». Sin colores de estado: ninguna de las dos es buena o mala.

Ponla en `SelectorVersion` (la cabecera del proceso) y en toda exportación.
